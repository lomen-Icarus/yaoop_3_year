# Языки объектно-ориентированного программирования — лабораторные работы (вариант 8)

Выполнил: студент группы ВИШ-14-24 Елимов М.Д.
Принял: доц. Смирнова Т.Н.

Каждая лабораторная — отдельная независимая папка: свой код, свой отчёт, свои файлы запуска.

| № | Папка | Тема | Задание (вариант 8) |
|---|---|---|---|
| 1 | [`lab1_vybor`](lab1_vybor) | Структуры выбора | удвоить a, b, c при a < b < c, иначе заменить модулями |
| 2 | [`lab2_cycles`](lab2_cycles) | Циклы | по номеру дня в году вывести число и месяц |
| 3 | [`lab3_arrays`](lab3_arrays) | Одномерные массивы | найти пары ai + aj = m |
| 4 | [`lab4_matrix`](lab4_matrix) | Многомерные массивы | строки квадратной матрицы с наибольшим и наименьшим произведением |
| 5 | [`lab5_objects`](lab5_objects) | Работа с объектами | класс «билеты на самолёты», файлы, добавление, удаление, сортировка |

## Запуск

- **IntelliJ IDEA:** `File → Open` → выбрать папку нужной лабы → запустить конфигурацию **Main**.
- **Windows:** `run.bat` в папке лабы (нужен JDK 8+ в PATH).
- **Linux / macOS:** `./run.sh` в папке лабы.

Отчёт каждой лабы лежит в `<папка>/report/Otchet_LabaN_Elimov.docx`.
