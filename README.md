# Языки объектно-ориентированного программирования — лабораторные работы (вариант 8)

Выполнил: студент группы ВИШ-14-24 Елимов М.Д.
Принял: доц. Смирнова Т.Н.

Каждая лабораторная — отдельная независимая папка: свой код и свой отчёт.

| № | Папка | Тема | Задание (вариант 8) |
|---|---|---|---|
| 1 | [`lab1_vybor`](lab1_vybor) | Структуры выбора | удвоить a, b, c при a < b < c, иначе заменить модулями |
| 2 | [`Laba2`](Laba2) | Циклы | по номеру дня в году вывести число и месяц |
| 3 | [`Laba3`](Laba3) | Одномерные массивы | найти пары ai + aj = m |
| 4 | [`Laba4`](Laba4) | Многомерные массивы | строки квадратной матрицы с наибольшим и наименьшим произведением |
| 5 | [`Laba5`](Laba5) | Работа с объектами | класс «билеты на самолёты», файлы, добавление, удаление, сортировка |

Лабы 2–5 устроены одинаково: `LabaN/LabaN.java` — программа (класс `LabaN`), `LabaN/report/` — отчёт и блок-схемы.
В `Laba5` ещё `Flight.java`, `FlightBase.java` и `flights.txt` (данные, программа читает их из текущей папки).

## Запуск

- **VS Code** (с расширением *Extension Pack for Java*): открыть папку лабы (`File → Open Folder → Laba2`), открыть `Laba2.java`, нажать **Run** над `main`.
- **Консоль** (нужен JDK 8+): в папке лабы
  ```
  javac -encoding UTF-8 *.java
  java Laba2
  ```
  В Windows при «кракозябрах» сначала выполнить `chcp 65001`.
- **Лаба 1** — по-старому: IntelliJ IDEA (`File → Open → lab1_vybor`) или `lab1_vybor/run.bat`.

Отчёт каждой лабы лежит в `<папка>/report/Otchet_LabaN_Elimov.docx`: титульный лист и скриншоты оставлены пустыми, их нужно добавить самостоятельно. Входные данные для скриншотов указаны в разделе 5 отчёта.
