# Лабораторная работа №3 — «Одномерные массивы» (вариант 8)

**Задание:** Дана последовательность целых чисел a1, a2, ..., an. Указать пары чисел ai, aj, таких, что ai + aj = m.

## Как запустить

**IntelliJ IDEA (рекомендуется):** `File → Open` → выбрать папку `lab3_arrays` → если сверху появится «Project JDK is not defined» — нажать *Setup SDK* и выбрать установленный JDK → запустить конфигурацию **Main** (зелёная кнопка ▶).

**Windows без IDE:** двойной щелчок по `run.bat` (нужен установленный JDK 8 или новее, `javac` и `java` должны быть в PATH).

**Linux / macOS:** `./run.sh`

Введите n, затем n чисел через пробел, затем m. Пример: `7`, `1 5 3 7 2 6 4`, `8`.
