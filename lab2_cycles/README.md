# Лабораторная работа №2 — «Циклы» (вариант 8)

**Задание:** По номеру дня в году вывести число и месяц в общепринятой форме (например, 33-й день года — 2 февраля).

## Как запустить

**IntelliJ IDEA (рекомендуется):** `File → Open` → выбрать папку `lab2_cycles` → если сверху появится «Project JDK is not defined» — нажать *Setup SDK* и выбрать установленный JDK → запустить конфигурацию **Main** (зелёная кнопка ▶).

**Windows без IDE:** двойной щелчок по `run.bat` (нужен установленный JDK 8 или новее, `javac` и `java` должны быть в PATH).

**Linux / macOS:** `./run.sh`

Введите номер дня от 1 до 365 (год невисокосный), например `33`.
