# Лабораторная работа №1 — «Структуры выбора» (вариант 8)

**Задание:** Даны действительные числа a, b, c. Удвоить эти числа, если a < b < c, и заменить их абсолютными значениями, если это не так.

## Как запустить

**IntelliJ IDEA (рекомендуется):** `File → Open` → выбрать папку `lab1_vybor` → если сверху появится «Project JDK is not defined» — нажать *Setup SDK* и выбрать установленный JDK → запустить конфигурацию **Main** (зелёная кнопка ▶).

**Windows без IDE:** двойной щелчок по `run.bat` (нужен установленный JDK 8 или новее, `javac` и `java` должны быть в PATH).

**Linux / macOS:** `./run.sh`

Введите три числа через пробел, дробная часть — через **точку**: `1 2.5 4`.
