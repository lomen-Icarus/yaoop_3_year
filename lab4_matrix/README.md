# Лабораторная работа №4 — «Многомерные массивы» (вариант 8)

**Задание:** Дана квадратная матрица. Найти строку с наибольшим и наименьшим произведением элементов. Вывести на печать найденные строки и произведения их элементов.

## Как запустить

**IntelliJ IDEA (рекомендуется):** `File → Open` → выбрать папку `lab4_matrix` → если сверху появится «Project JDK is not defined» — нажать *Setup SDK* и выбрать установленный JDK → запустить конфигурацию **Main** (зелёная кнопка ▶).

**Windows без IDE:** двойной щелчок по `run.bat` (нужен установленный JDK 8 или новее, `javac` и `java` должны быть в PATH).

**Linux / macOS:** `./run.sh`

Введите порядок n, затем n строк матрицы по n целых чисел. Пример: `3`, `1 2 3`, `4 5 6`, `-1 2 2`.
