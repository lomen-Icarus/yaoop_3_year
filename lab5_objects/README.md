# Лабораторная работа №5 — «Работа с объектами» (вариант 8)

**Задание:** Класс со сведениями о наличии билетов на самолёты: номер рейса, пункт назначения, время вылета, количество свободных мест. Программа выдаёт время отправления самолётов в заданный город и наличие свободных мест на определённый рейс. Данные и результаты хранятся в файлах; есть добавление, удаление и сортировка записей по заданному полю.

## Как запустить

**IntelliJ IDEA (рекомендуется):** `File → Open` → выбрать папку `lab5_objects` → если сверху появится «Project JDK is not defined» — нажать *Setup SDK* и выбрать установленный JDK → запустить конфигурацию **Main** (зелёная кнопка ▶).

**Windows без IDE:** двойной щелчок по `run.bat` (нужен установленный JDK 8 или новее, `javac` и `java` должны быть в PATH).

**Linux / macOS:** `./run.sh`

Программа работает через меню (пункты 0–6). Данные читаются из `flights.txt`, результаты запросов дописываются в `results.txt`. Время вылета вводится в формате `ЧЧ:ММ`, например `07:15`.
